# AFU-Sandbox
Garry's mod in Airframe Ultra! Currently only adds Noclip/Flight and the Toolgun/EntitySpawner but much more is planned!

.

.

.

## Controls

Start flight: **Hold E + Crouch + Jump**

End flight: **Hold E**

.

Spawn Toolgun: **Crouch + Menu Button**

Toolgun Secondary Fire: **Hold secondary fire to open the EntityPrototype selector radial menu, click while selecting a sub-menu to enter it**

Toolgun Primary Fire: **Spawn selected EntityPrototype**
